My first game - VoidSweeper a roguelite minesweeper 




how to run (on windows - idk how to run it on mac)
1. download folder which will have README, src and sprites
2. Open powershell
3. Compile src file - `javac -d out src/*.java`
4. Run Main - `java -cp out Main`


!! All images and sprites are AI generated (through chatGPT)
